# Triage Labels

工程技能中的五种工单分诊角色映射如下。

| Skill role | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由 agent 自主实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不计划处理 |

技能提到这些角色时，使用表中的 GitHub label。项目已有的 `bug`、`enhancement` 等分类标签可继续使用。
