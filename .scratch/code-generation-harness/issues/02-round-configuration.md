# 02：文件级轮数配置与会话隔离

Type: task
Status: ready-for-agent
Blocked by: 01

## What to build

用户在自然语言片段执行前为特殊全局对象的 maxRounds 属性赋值，即可调整该文件后续新生成的轮数上限。不同生成会话彼此独立。完整契约以[规格](../spec.md)为准。

## Acceptance criteria

- [ ] 默认 10，支持正的安全整数；非法值在请求前失败，不新增环境变量或公共配置方法。
- [ ] 每次 OpenAI 缓存未命中时读取配置，当前会话固定使用该快照；下一次新生成可读取新值。
- [ ] Jev 与代码缓存命中忽略轮数配置，包括无效值。
- [ ] 生成阶段失败不缓存，修正成功后仍复用生成代码。
- [ ] 并发生成历史和配置不会互相污染；原始上下文在当前会话固定。
- [ ] 使用公开生成接口和模拟 HTTP 逐次红绿验证；已有 Babel 测试通过，必要时验证编译后的配置赋值可到达 core。
