# 01：多轮代码提交与修正

Type: task
Status: ready-for-agent
Blocked by: None

## What to build

代码生成在漏交或交错函数体时保留对话并反馈错误，直到模型提交一份符合约定的函数体，或达到默认 10 轮上限。完整行为以[规格](../spec.md)为准。

## Acceptance criteria

- [ ] 在公开生成入口接入内部 Harness；消息历史属于本次调用。
- [ ] 漏调用追加 user 提醒；JSON / 参数错误及未知工具回填 tool 错误；同轮多个完整调用逐一反馈并要求重交。
- [ ] 有效提交立即结束；显式空函数体有效，不读取正文代替提交。
- [ ] 默认最多 10 轮，包含首轮；第 10 轮可成功，无第 11 次请求。
- [ ] 拒绝、过滤、截断和损坏响应立即失败；保留 SDK 网络错误处理。
- [ ] 通过公开入口和模拟 HTTP 的逐次红绿验证覆盖上述行为；保持函数体包装、缓存、eval 与 Jev 行为。
- [ ] 每轮仍强制 final_output、关闭并行调用、不添加 strict。

## Implementation notes

使用 tdd；从集成分支开始，完成前合并集成分支最新提交。测试边界已在规格及任务图确认，不重新请求用户确认。暂不暴露轮数配置；下一张工单负责这一完整能力。
